# SHASHETY PRO — Android TV

تطبيق Android TV أصلي بالكامل لخادم الوسائط الذي يحدده المستخدم، مع إعداد محفوظ، تشغيل Media3، وتنقل بالريموت. لا يستخدم WebView.

## ما يفعله التطبيق

- عند أول تشغيل فقط، يطلب **اسم المضيف** و**المنفذ** (الافتراضي `80`) ويحفظهما محليًا.
- يقرأ كتالوج الوسائط من واجهة JSON في الخادم ثم يرسم البطاقات ومسار التركيز محليًا.
- واجهة تلفاز فضية معدنية موحّدة: الشريط العلوي، البحث، عرض الكل، والحلقات.
- لا يعيد طلب الخادم في التشغيل اللاحق؛ تغيير الخادم يتم من زر **الإعدادات** أو زر `Menu` في الريموت.
- يدعم روابط `http://` لخادم LAN. قبل النشر العام يجب تحويل الخادم إلى HTTPS أو تقييد HTTP على شبكتك الخاصة.
- يوفر مشغّل Android أصليًا مبنيًا على Media3 عند استدعائه من موقعك.

## تحكم الريموت في المشغّل

| زر الريموت | الإجراء |
|---|---|
| OK / Enter | تشغيل أو إيقاف مؤقت |
| يمين | تقديم 30 ثانية |
| يسار | ترجيع 10 ثوانٍ |
| رفع/خفض الصوت | تحكم صوت النظام |
| Stop | إيقاف الفيديو والخروج من المشغّل |
| Back | رجوع من المشغّل |
| Z | التبديل بين احتواء الصورة، التكبير، والملء |

تظهر واجهة Media3 القياسية شريط الوقت، والمدة، وأزرار التقديم والترجيع عند تحريك أي زر تحكم.

## واجهة الخادم المطلوبة

المشروع الحالي يتصل بمسار `iptv` المحفوظ على الخادم، ويستخدم `api.php` لإرجاع الأقسام، البحث، الحلقات، والقنوات. راجع `MainActivity.kt` قبل تغيير عقد واجهة الخادم.

## البناء والتجربة على TCL Smart TV Pro

يتطلب البناء JDK 17 وAndroid SDK، ثم:

```powershell
./gradlew.bat assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

سيكون ملف APK الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## نطاق الإصدار

هذا المشروع لا يتضمن DLNA أو Web Cast أو WebView. يحتاج الخادم واجهة JSON صغيرة لأن التطبيق الأصلي لا يقرأ صفحة HTML.
